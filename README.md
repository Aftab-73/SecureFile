# 🔐 SecureFile

SecureFile is a Python-based application designed to securely encrypt and hide sensitive data inside image files.
It provides a simple graphical user interface (GUI) that allows users to protect confidential files using encryption and steganography techniques.

---

## 🚀 Features

* 🔑 **File Encryption** – Securely encrypt sensitive files.
* 🖼 **Steganography Support** – Hide encrypted data inside images.
* 🖥 **Simple GUI Interface** – Easy to use graphical interface.
* 🔒 **Data Protection** – Helps keep private information secure.
* ⚡ **Lightweight & Fast** – Built using Python for efficiency.

---

## 🛠 Technologies Used

* **Python**
* **Cryptography**
* **Steganography**
* **GUI (Tkinter / Python GUI tools)**

## ⚙ Installation

1. Clone the repository:

```
git clone https://github.com/Aftab-73/SecureFile.git
```

2. Move to the project directory:

```
cd SecureFile
```

3. Install dependencies:

```
pip install -r requirements.txt
```

---

## ▶ Running the Application

Run the SecureFile GUI application:

```
python src/securefile/gui.py
```

---

## 🧪 Testing

To run the project tests:
